# Doctor Appointment Booking Application

## Project Description
A full-stack web application that allows users to search for doctors, book appointments, and leave reviews. It features user authentication, a notification system, and profile management.

## Setup Instructions
1. Clone the repository: `git clone <your-repo-url>`
2. Navigate to the project directory: `cd doctor-appointment-app`
3. Install dependencies: `npm install`
4. Start the development server: `npm run dev`
